System Capabilities

How RookAI bypasses dependency conflicts while maintaining deep diagnostic depth.

Decoupled Inference

The heavy TensorFlow backend environment and pre-trained SavedModel weights run safely containerized, eliminating driver fragmentation entirely.

  • Zero host ML footprint
  • Immutable execution stack
  • Isolated process bounds

Dual Operational Modes

Run via the interactive ANSI-colored terminal dashboard for fast server administration, or initialize the rich PyQt6 desktop layout for deep monitoring visualization.

  • Asynchronous QThread tasks
  • Real-time progress trackers
  • Dynamic UI alert triggers

Session Reporting

Managed directly via the integrated local logging framework to generate secure, standardized markdown summaries without external database tracking dependencies.

  • Automated session caching
  • Local history purging
  • Local markdown exports

Quick Start Deployment

Initialize the isolated backend container and spin up your local client layout.

01

Build the Core Engine

Clone the core repository from GitHub and build the standardized container image environment to assemble your local tensor processing nodes:

git clone https://github.com/Ryuu-Naisho/RookAI.git
cd RookAI
docker build -t rookai-core:latest .
02

Set Up the Native Client

Because the visual client communicates with your native Linux window manager (X11/Wayland), build a lightweight local virtual environment outside of your container:

python3 -m venv venv
source venv/bin/activate
pip install PyQt6 numpy
03

Boot the Security Core

Launch the asynchronous dashboard interface while keeping your virtual environment session active to begin real-time diagnostic auditing:

python gui/main_window.py
